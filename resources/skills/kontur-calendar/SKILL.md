# Календарь

Календарь живёт в Exchange (EAS) контура. Создание встречи — единственная
операция записи, которая есть у агента.

```
calendar_create_meeting {
  subject,                     тема
  startsAt,                    ISO-8601 с таймзоной
  endsAt,                      ISO-8601 с таймзоной
  attendees?,                  список адресов
  location?,                   «Переговорка 4» или ссылка на Толк
  body?,                       повестка
  allDay?,                     событие на весь день
  env?                         bank | ecom
}
```

Время **всегда** с таймзоной: `2026-10-20T15:00:00+03:00`. «Завтра в три»
переводи в абсолютное время от текущей даты и покажи пользователю, какое
именно время подставил, — ошибка на час здесь дороже лишней строки в ответе.

Участников указывай адресами (`ivanov@example.com`). Имя из адресной книги
агент сам не резолвит: если дан только «Петя», спроси адрес или найди его в
переписке через `kontur_search`.

## Посмотреть расписание

Отдельного инструмента чтения календаря нет. Встречи приходят в общую ленту:
`kontur_my_day` возвращает их вместе с задачами и письмами (`kind: 'event'`,
со временем начала). Для «что у меня сегодня» этого достаточно; за деталями
конкретной встречи — `kontur_search` по теме.

## Как действовать

1. Перед созданием свериться с `kontur_my_day`: не ставишь ли встречу поверх
   уже существующей.
2. Приглашение уходит участникам письмом — это действие, видимое другим.
   Создавай встречу, когда пользователь прямо попросил; состав участников,
   время и тему перед отправкой покажи одной строкой.
3. Если контур не поднят (VPN), сервер ответит ошибкой — это не повод
   повторять запрос, скажи пользователю.
